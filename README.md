# Fall2026InClass

Example in-class code from Fall 2026 CSCI 2210 at NMSU

Most examples will be small single-file examples that can be compiled as:
```
g++ filename.cpp
```
(Replace _g++_ with _gcc_ for C code). The above command will create the 
executable file named _a.out_, so if you want a better name you must use
```
g++ -o execname filename.cpp
```
This will give you a file named _execname_ -- you should use a name that is 
appropriate (often the base _filename_ of the _.cpp_ file.

I will try to keep the code heavily commented, so it is __meant to be read__,
not just run.
